<objective>
Remove the dual-server architecture from http.ts and fix port binding to make the server Railway-compatible.

Purpose: Railway's proxy can only reach a process bound to 0.0.0.0. The current code binds to 127.0.0.1 and spawns a second HTTPS server on port 3443 using a self-signed certificate — both of which are incompatible with Railway. This plan removes all dual-server machinery and corrects the bind address and port variable.

Output: A modified http.ts that starts a single Express server on 0.0.0.0:${PORT} with no oauthApp, no selfsigned usage, and no port scan loop. TypeScript compilation must pass after the changes.
</objective>
